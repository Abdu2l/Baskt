# Baskt

Android 向けのモダンな音楽プレイヤー。ローカルファイルと YouTube Music に対応し、
Material 3 デザイン、動的カラー、多数のプレイヤースタイル、同期歌詞、豊富な
カスタマイズを備えています。

- ソース: https://github.com/Abdu2l/Baskt
- 不具合報告: https://github.com/Abdu2l/Baskt/issues
- プライバシー: [PRIVACY.md](PRIVACY.md) を参照

## 謝辞

Baskt は [ArchiveTune](https://github.com/rukamori/ArchiveTune)
（[Metrolist](https://github.com/mostafaalagamy/Metrolist) および
[InnerTune](https://github.com/z-huang/InnerTune) がベース）のフォークです。
