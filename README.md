# Baskt

A modern music player for Android with local file and YouTube Music support —
Material 3 design, dynamic album-art colors, many player styles, live synced
lyrics, and deep customization.

## Features

- Ad-free playback with background listening
- Local files, YouTube playlists, liked songs, subscriptions
- EBU R128 normalization, tempo/pitch/speed, crossfade, system EQ
- Live synced lyrics with translation and romanization
- Listening statistics, Last.fm scrobbling, ListenBrainz sync
- Discord Rich Presence, widgets, Android Auto
- 9+ player styles, 8 player background styles, mini-player styles
- Dynamic color theming, gestures, animation and layout tuning

## Building

See [CONTRIBUTING.md](CONTRIBUTING.md) for build instructions.

```sh
git clone https://github.com/Abdu2l/Baskt.git
cd Baskt
git submodule update --init --depth 1
```
